Most common LG washing machine faults

  • Not draining, with the OE code.
  • Shaking or not spinning when the load is unbalanced (UE).
  • Leaks or mould on the door seal of front-load machines.
  • Door lock problems (dE).
  • Water not entering (IE).
  • Motor errors (LE).

LG washing machine error codes

Codes vary by model. These are the common meanings:

  • OE: drainage problem.
  • IE: water inlet problem.
  • UE: unbalanced load.
  • dE: door closing or lock problem.
  • LE: motor problem.
  • PE: water level sensor problem.
  • FE: water level too high (overfill).
  • CL: child lock is on; not a fault.

A guide only. Check your manual, and tell us the code and model when you call.

How we diagnose an LG washing machine

We start with the code on the display, then check the part it points to: the drain filter and pump for OE, the inlet valve for IE, the door lock for dE, the water level sensor for PE and the motor for LE. We don't suggest replacing anything before that.
